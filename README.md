# XNAGameStudio – Visual Studio 2022 Rebuilds

This repository contains rebuilt and adapted versions of legacy XNA-era
projects, updated to run in modern development environments such as
Visual Studio 2022.

The purpose of this repository is preservation, education, and technical
continuity. It does not redistribute the original XNA Game Studio tooling.

---

## Purpose

Microsoft XNA Game Studio and its original Visual Studio integration are no
longer maintained or supported. As a result, many historical XNA projects
can no longer be built or executed in current environments without
significant modification.

This repository exists to:

- preserve XNA-era project structure and development workflows
- document how those projects can be rebuilt using modern tools
- provide working reference implementations for educational use
- ensure that legacy XNA projects remain buildable and runnable today

All projects in this branch have been **rewritten, adapted, or rebuilt**
to function under Visual Studio 2022.

---

## What This Repository Is

- A collection of **XNA-era project rebuilds**
- Targeted at **Visual Studio 2022**
- Intended for **educational, archival, and reference purposes**
- Focused on workflow and behavior preservation rather than original tooling

---

## Content and Tooling

Some projects may reference XNA Framework 4.0–era APIs or assemblies in order
to preserve compatibility and behavior. These references do not imply
redistribution.

Where required, rebuilt or standalone tooling is used to replace functionality
that was previously provided by the original XNA Game Studio integration
(e.g. content build workflows).

Any required XNA Framework components must be obtained separately by the user
from legitimate sources.
